# Product Management Service

![Build Status](https://github.com/ahmadhelmiafandi/devops-capstone-project/actions/workflows/ci-build.yaml/badge.svg)

This service provides CRUD operations for managing products in a catalog.

## Features
- Create, Read, Update, Delete products
- List all products
- Search products by name, category, or availability

## Getting Started
1. Install dependencies: `npm install`
2. Run the server: `npm start`
3. Run tests: `npm test`

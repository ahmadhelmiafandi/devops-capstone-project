# User Stories

## Create Account
**As a** User  
**I want to** be able to create an account  
**So that** I can access the system

**Acceptance Criteria:**
- User provides a username and password.
- System validates the input.
- System creates the account and returns a 201 status.

## List Accounts
**As a** System Administrator  
**I want to** list all accounts  
**So that** I can monitor user activity

**Acceptance Criteria:**
- Administrator requests a list of accounts.
- System returns a list of all registered accounts.
